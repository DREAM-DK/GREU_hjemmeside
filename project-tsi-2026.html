Economic Analysis for Climate Action 2: GreenREFORM-EU in 18 Member States

From October 2026 to January 2029 the European Commission funds DREAM to bring GreenREFORM-EU to 18 Member States. The project trains national teams, moves the code to the open-source language Julia, automates the supply of Eurostat data and builds new sectoral sub-models for the sectors the countries ask for.

Commission project page Model documentation

Why it was set up

The amended Directive 2011/85/EU on national budgetary frameworks asks Member States to assess and report the macro-fiscal effects of climate change and climate policy. Many ministries lack the tools, the data and the staff to do it. Their work tends to cover single aspects. Climate risk is still rarely part of forecasts and budget plans.

The TSI 2024 project built GreenREFORM-EU for five institutions. It showed that collecting data by hand was the main delay for national teams. Eighteen Member States asked the Commission for further support.

What it is part of

The Commission project is called Economic Analysis for Climate Action. It has three pillars:

  1. The GreenREFORM-EU model and similar models.
  2. Analytical tools for macro-fiscal impacts, nature-related risks and the costs of climate events.
  3. Integrating climate risk into fiscal and budgetary planning.

DREAM’s grant covers the first pillar. This page describes that part only.

What it sets out to do

  1. Deliver a fully functional, open-source GreenREFORM-EU model in Julia, with technical documentation, a user guide and server access.
  2. Give national teams a three-day introduction seminar, online training, country visits and a final workshop.
  3. Build an automated Eurostat data pipeline, and a standard interface for countries that run their own energy-system models.
  4. Build a benchmark technology data set and guidelines for a common EU technology data set.
  5. Design, code, calibrate and hand over one or two new sectoral sub-models.

What the project does

  • Code and model. The code moves from a mix of Python, GAMS and gamY to Julia, before the new teams start. A GAMS licence is then no longer needed. A solver licence is still needed. DREAM keeps the model, the documentation and the user guide up to date during the project.
  • Server. Designated staff in each Member State get restricted access to a Linux server hosted by the Technical University of Denmark. The project provides the solver licence.
  • Training. A joint three-day seminar in Copenhagen. Online training with exercises. A two-day visit by DREAM experts to each country in the introduction track. A final joint two-day workshop on the new sub-models.
  • Data. An automated pipeline that imports Eurostat input-output tables, sector accounts and emissions and prepares them for the model. DREAM also publishes calibration guidelines and a paper that calibrates the model to Danish data as a worked example.
  • Technology data. A benchmark technology data set for Denmark, with costs, energy mix, capital intensity and emission-reduction potential. It is the blueprint for a common EU technology data set, which an external provider builds.
  • Energy-system models. GreenREFORM-EU solves its energy technology model and the macroeconomy together. Some countries also keep their own energy-system models. The project designs a standard interface so that they can exchange baseline scenarios with GreenREFORM-EU, and tests it with one country.
  • New sub-models. One or two sectoral sub-models. The countries decide the scope during the project.
  • Technical report. A final report on the Danish benchmark calibration, with examples from other countries where possible, and with policy experiments.

Timeline

  • October to December 2026. Preparation. The Julia code base and the first documentation.
  • January 2027 to November 2028. Work with the Member States.
  • December 2028 to January 2029. Final reports.

Who takes part

Eighteen Member States take part. The roles differ:

  • Introduction track, nine countries. Cyprus, Germany, Estonia, Greece, Spain, Latvia, Malta, Portugal and Sweden. They have no working model of this kind. They receive a customised model, server access, training and a country visit.
  • Implementation track, thirteen countries. Austria, Belgium, Cyprus, Germany, Greece, Spain, Finland, Italy, Latvia, Malta, the Netherlands, Portugal and Sweden. They work on national calibration, Eurostat data and the link to energy-system models, and on new sub-models.
  • Both tracks. Cyprus, Germany, Greece, Spain, Latvia, Malta, Portugal and Sweden.
  • Advisers. Austria, Belgium, Finland and Italy took part in TSI 2024. They advise the introduction track.
  • Observers. France, Slovakia and Slovenia.
  • Denmark. Advisory role.

Country progress is described on the country pages as each institution agrees to publish it. This page does not report it.

What it delivers

DREAM publishes the public outputs on this website.

  • Code. An open-source Julia code base, ready in December 2026. The final code base follows in November 2028.
  • Documentation and user guides. First versions in January 2027. Final versions in November 2028. A user guide for the server in April 2027.
  • Training. Seminar and training material, with online presentations.
  • Data pipeline. A technical note on the Eurostat pipeline, by June 2027.
  • Calibration. Guidelines and a benchmark calibration paper, by December 2027.
  • Technology data. Guidelines, by September 2027. The benchmark data set has restricted access.
  • Energy-system interface. A concept note and a technical report, by December 2027.
  • New sub-models. Code and documentation, by September 2028. Their benchmark data set has restricted access.
  • Final technical report. By November 2028.

Dates are planned dates from the grant. They can move.

Results

The project has published no results yet. Analyses appear under Analyses as they are published.

The model it builds on, and the first public analysis, come from the TSI 2024 project. The refined edition it starts from comes from Version 2.0.
