## What this project is, and is not

It is the first project on the site where DREAM builds a model for a
jurisdiction **outside the EU** and outside the climate framing. The Faroe
Islands are not in the European Union. The model is about fiscal
sustainability, not emissions. The page says so plainly, in "Relation to
GreenREFORM-EU", because a reader arriving from Applications will otherwise
assume this is another climate calibration.

It is also the clearest evidence on the site for a claim the Foreword makes
about the model: that it is "a general framework for models whether or not
they contain a climate component". The Faroese model uses the macroeconomic
core without the climate block. This page does not make that argument
explicitly — it is the homepage's point to make, and the homepage still owes
it a home — but the project is the demonstration.

## Flags for the team

1. **GREU3 was removed, by instruction.** The supplied text says three times
   that the model builds on "GreenREFORM-EU 3 (GREU3)". On 5 November 2026 the
   instruction was that the page should relate only to Version 2.0, which is
   the edition this site documents. The page therefore says "the macroeconomic
   core of GreenREFORM-EU", and attaches no version number to the Faroese
   model. Version 2.0 does appear twice on the page, in "Relation to
   GreenREFORM-EU" and under "Read more", but only as the edition this site
   documents and to say that this project is not a Version 2.0 output.

   This is worth understanding rather than just recording. Saying "the
   macroeconomic core of GreenREFORM-EU" is true of the model as a lineage and
   avoids naming an edition the site does not document. Saying "built on
   Version 2.0" would have been a stronger claim than the source supports,
   because the source says 3. The unnumbered form was chosen as the honest
   middle. **If the Secretariat or the project team reads this page, they may
   notice the version is absent.** Confirm the wording with them before
   publishing.

2. **Julia was removed, by instruction.** The supplied text lists the first
   deliverable as "Macroeconomic model. A model adapted to the Faroese economy,
   **with source code written in Julia**." The page says only "A model adapted
   to the Faroese economy".

   The reason is that Julia and Version 2.0 cannot both be true on one page.
   Version 2.0 is GAMS with Python and gamY; `Get the model` says so. A page
   pointing at 2.0 while listing a Julia deliverable would contradict itself in
   two screens. Agreed on 5 November 2026 to drop it.

   Note what this implies: a Faroese model written in Julia is built on the
   Julia core, which is the TSI 2026 work, which is GREU3. The two removals are
   the same removal. If the site later documents 3.0, both should come back
   together, and this page should be revisited as a whole rather than patched.

3. **No links.** The project has no public page. The Secretariat of the Faroese
   Economic Council (Búskaparráðið) has a website; it is not linked here
   because nothing on it was supplied or checked. Ask whether the Secretariat
   wants to be linked, and whether it has an announcement.

4. **Clearance.** The Secretariat has not seen this page. It is named
   throughout, and the project is described as commissioned by it. The approval
   document is `content/approvals/approval-faroe-islands.docx`, 5 November
   2026, in the same form as the ones sent to Viet Nam, FinReform and Belgium.
   It is written but not sent. Its first two questions are flags 1 and 2 below,
   put to the Secretariat as questions rather than as decisions already taken,
   because both removed something they supplied.

5. **Faroese name.** The Secretariat's own name in Faroese is Búskaparráðið.
   The page uses the English form only. Ask whether they want the Faroese name
   given alongside, as the FinReform page was asked about its Finnish title.

6. **Dates are a year range, not dates.** The supplied text gives "2026–2027"
   and "the final model is expected to be delivered by the end of 2027". No
   start date. The Applications card therefore reads "2026 – 2027", which
   matches the other cards' pattern without inventing precision.

7. **Money stays off**, as on every other project page. No figure was supplied
   in any case.

8. **"Existing projections ... developed by DREAM as part of other projects".**
   The supplied text is deliberately vague about which projections. The page
   repeats the vagueness rather than guessing at Faroese demographic work.
   If the team can name the source, the sentence improves.
